# Agent skills for running cold email with AI

68 self-contained public skills for agents that read `SKILL.md`. Each skill states its prerequisites and includes Valid/Invalid examples.

## Install

```bash
npx skills add carlosalminaque/cold-email-agent-skills
```

Installation grants no external service permissions. Choose one skill or the whole collection.
